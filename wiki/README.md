# Wiki copy

These pages are a copy of the official [mv4wd/RCHourglass wiki](https://github.com/mv4wd/RCHourglass/wiki/).

To publish them as a GitHub Wiki on this repo:

1. Enable Wiki in the repository settings.
2. From a machine logged in to GitHub:

```bash
git clone https://github.com/mv4wd/RCHourglass.wiki.git
cd RCHourglass.wiki
git remote set-url origin https://github.com/pontusAndersson/CyclingHourglass.wiki.git
git push -u origin master
```

Then open https://github.com/pontusAndersson/CyclingHourglass/wiki
